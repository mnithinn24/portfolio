## Step-by-Step: Publish With GitHub Pages

1. Open GitHub and sign in to `mnithinn24`.
2. Create a new public repository named `portfolio`.
3. Upload these portfolio files into the repository root:
   - `index.html`
   - `style.css`
   - `script.js`
   - `assets/Nithin_Resume.pdf`
4. Open the repository `Settings`.
5. Go to `Pages`.
6. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
7. Click `Save`.
8. Wait 1-3 minutes.
9. Open `https://mnithinn24.github.io/portfolio/`.
